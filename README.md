# Espresso Sound Timer | 意式浓缩按键声纹计时器

一个无需服务器、纯本地运行的浓缩咖啡声控计时网页工具（PWA）。通过手机麦克风识别你专属的咖啡机按键“哒”声，自动完成**开始计时**与**结束计时**。

🔗 **在线使用（推荐用 iPhone Safari 打开）：** https://prowenw.github.io/espresso-timer/

## 核心特性
- **一键双声纹采集**：录制 3 组「开始键 + 结束键」声音样本，自动拆分并永久保存在本地浏览器（`localStorage`），下次打开无需重录。
- **三重抗干扰过滤**：结合 `1.2kHz–12kHz` 高频声纹匹配、按键/人声能量比过滤与 `85ms` 短促脉冲校验，有效排除说话声与水泵持续嗡嗡声。
- **零服务器隐私安全**：所有音频分析均在设备本地实时完成，不上传任何录音数据。

## iPhone 快速使用
1. 用 **Safari** 打开 [https://prowenw.github.io/espresso-timer/](https://prowenw.github.io/espresso-timer/)，点击「分享 → 添加到主屏幕」。
2. 打开后点右上角「**采集/管理**」，按提示录制 **3 组**按键声（每组先按开始键、停顿 1 秒后再按结束键）。
3. 以后每次萃取前点击「**开始监听**」并授权麦克风，听到第 1 声按键自动开始、第 2 声自动定格时长。
